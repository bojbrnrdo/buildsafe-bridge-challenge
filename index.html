ENGINEERING GUIDE

How BuildSafe works

1. Read the mission

Every project has a fixed span, target load and maximum budget.

2. Build your section

Choose material, beam width, beam depth and the number of parallel girders.

3. Run the load test

The truck applies the design load and the game checks stress, deflection and cost.

4. Optimize

A safe design passes, but an efficient design earns more points. Aim for high utilization without exceeding limits.

Simplified beam model M = PL/4 · I = bh³/12 · σ = Mc/I · δ = PL³/(48EI)

Each parallel girder shares the applied load equally. The game uses simplified educational material properties and cost factors.
